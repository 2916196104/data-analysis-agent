# 阶段 3.5：回答稳定性诊断和实施设计

审查日期：2026-11-01。本报告在代码修改前形成，依据第三阶段源码、验收报告、真实模型合成结果和日志。工作区开始时干净。不修改意图理解、主题归并、数据库或前端布局。

## 已证实的根因

| 问题 | 证据与判断 | 最小修正 |
| --- | --- | --- |
| 草稿超时 | 历史 12 次真实案例运行中 4 次 generation_timeout；已返回草稿约 181–297 输出 token，单例延长预算后耗时 27.442 秒。原每请求 15 秒与观察到的服务延迟不匹配。历史没有首 token/服务排队数据，不能断言全部来自模型推理或网络 | 简短别名、短协议说明、缩减目录和输出长度；固定原默认超时做同数据对照，分别报告生成与复核耗时 |
| 所谓 Schema 不符合 | 可取得原始正文的两份失败草稿均通过 json.loads 与 InsightDraft 校验；实际为文字/实体规则拒绝。其余历史 invalid_generation 缺少正文和细分原因，不能追认成 Schema 错误 | JSON、Schema、未知引用、数字、实体、引文、范围和语义拒绝分别编码；接受单层 JSON 代码围栏等无歧义格式规范化 |
| 引用误拒绝 | 长 finding ID 在 focus、fact_ids 和每个文字占位符中重复；已知名称的直写/引号曾被当作未验证引文。一级维度重绑定已修正一部分，但强制所有解释包含占位符仍过严 | 模型使用短别名和独立 refs，允许不含占位符的有限解释；已知实体只做精确绑定，不模糊匹配新实体、数字或原文 |
| 支持性复核 | 原提示第一条仅允许“统计关系解释或建议”，末尾才补充概念释义，口径不一致；复核输入是未展开的长占位符和同一份冗长目录，不能看到本地 evidence 占位符的实际内容。已知拒绝只有 unsupported_interpretation，无具体理由 | 只复核自由解释；引用与统计由程序验证。复核只接收相关事实、已绑定名称和本地证据标记；明确允许描述性释义，禁止新增原因/性能/商业事实，逐条记录理由 |
| 失败扩大 | 一条解释被拒绝即丢弃整个模型草稿和其他解释，退回默认重点；所有错误归入两个宽泛错误码 | 保留已验证重点与已通过的解释，拒绝项单独记录；没有可发布解释时仍明确降级，不用更改成功率口径掩盖失败 |
| 模板冗余 | 趋势摘要已说样本不足，解释又重复同一命题；比较摘要和数值行重复性能限制；不论用户问题都追加通用说明。仅凭重复限制也会被算成“解释成功” | 精确去重已经发布的命题，把有支持的解释与无新增价值复述区分；必要样本、候选、分母和失败限制保留 |

历史 `answer-phase3-live-*` 三轮加延长预算共 12 次案例运行，5 次 invalid_generation、4 次 timeout、3 次 llm；只有一次发布自由解释。已知 support review 拒绝不能仅凭宽泛标签判断为误拒绝；本阶段通过正负对照重新测试。

## 协议和接口设计

保留 PublicAnswer 与外层任务接口，保留 v1/v2 历史草稿校验。新模型传输采用短引用目录和 `focus + insights`，文字中不强制复制长 ID。解析后转换为稳定事实 ID；所有数字、原文、商品及范围仍从已验证目录绑定。只对可精确验证的命题直接发布，语义自由解释继续独立复核。

模型调用总上限仍为两次，传输重试也占额度；默认每请求 15 秒、总预算 30 秒不变。生成与复核在数据库事务关闭后进行。不用增加超时掩盖协议问题，不在测试中向模型发送真实评论。

新增/修改范围：`review_insights.py`、`review_answers.py`、必要的 `review_answer_facts.py`，固定合成案例/评测脚本、针对性测试与模拟模型适配。压缩层已保留所需事实和状态，优先不修改。

## 验证和交付边界

- 不少于 30 个固定正常合成案例，另列预期拒绝/超时/partial/failed 控制；同时报告模型适用案例的降级率，避免零调用案例稀释指标。
- 同一份经过验证的合成快照分别运行第三阶段基线和新版本；保留真实响应、事实核对、原因分布、token、各阶段和总体时间分布。旧版本从明确的 Git 版本读取，不伪装成历史模型评测。
- 伪造数字、原文、实体、来源、样本外推和因果推断不能借规范化通过；语义评审不能覆盖程序验证。
- 逐题阅读前后回答，另提供盲序真人评审材料。不将同模型评分或本 Agent 自评称作人工验收；未得到真人结果时明确报告未完成。
- 目标为正常固定案例非预期降级率不超过 20%、已知伪造发布为零；另报告有效解释发布率、复核通过率和数据范围限制。未达目标照实记录瓶颈，不进入第四阶段。
