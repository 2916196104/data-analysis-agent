## 阶段隔离与限制

阶段 A 的 builder 只打开四个代码固定的原始来源：原候选问题集、评论 CSV、历史行观察和历史观点观察，逐文件验证冻结摘要。原候选问题集本身包含过去的候选说明等字段，builder 仅读取问题、范围、指定候选和历史原始字段；不读取或携带其建议判断、人工支持关系及答案。两题候选顺序由用户本轮固定，不是新搜索排序。

阶段 B **没有实现预测器**。当前独立子进程以 `python -I` 运行，只读标准输入的 JSON，禁止任何命令行参数；严格校验各层字段集合、冻结问题和范围、来源摘要、候选完整内容摘要、历史观点及文本区间。它只返回 `INPUT_PRECHECK_ONLY`，不能输出预测、判断、拒答或成绩，也不接受文件路径、插件或可执行代码。非法嵌套字段及把 Gold 路径作为参数或输入均在测试中被拒绝。

禁止读取范围在私有输入协议中列示，包括 Gold Reference、人工裁决和审批事件、人工引用复核、评分及预测文件。**实际隔离能力的范围必须说明**：标准输入白名单和不接收文件路径，只证明当前固定预检程序的接口不能要求它读取这些文件；`python -I` 并不剥夺同一 Windows 用户对文件的操作系统权限，也不能约束将来任意判断器代码。未来真正的预测进程必须具备并通过独立验证的操作系统级最小权限文件隔离，确认无法打开 Gold、事件及评分文件；未完成前，不得将 B 阶段称为盲态安全 READY。现阶段没有运行 B，因此不把有限接口测试描述为对未来模型进程的完整隔离证明。

阶段 C 仅保留[评分协议](E:/AllProject/data-analysis-agent/outputs/agent-stage2-real-business-readiness-20261111/p2-b1-blind-input-v1/scoring-protocol.v1.json)。将来预测需先单独授权、写入并完成不可修改的封存及摘要，再由独立评分进程读取 Gold；目前没有实现评分器或封存伪预测。

## 来源与内容核验

输入包保留原题、商品、日期、来源、数据集、review/annotation 身份、完整评论、标注 profile、模型/提示版本、原始观点键及原始位置、来源和正文摘要。builder 按 CSV 多行记录的起始物理行核对文本；再对历史行观察的评论、annotation、状态、版本以及观点观察的每个历史键和字段进行交叉校验，核对观点在完整评论中的 Unicode 切片与摘要。任一来源摘要、身份、内容或区间不一致即阻断。历史观察仍为 `history_unproven`，不是当前数据库或 P0 事务快照认证。

严格白名单不包含人工 A/B/C/D/E/F、`candidate_decisions`、人工理由、许可 Q 编号或评分；观点只来自历史观点原样字段。人工 Q 如恰好与原历史观点是同一文本，不构成由人工切片替换历史观点；本工具不读取人工 Q 文件，且测试逐条对照了原历史观点全集与顺序。

预检协议还绑定每个候选的完整规范化对象摘要，故改写身份、调换候选、删减观点、改变正文或伪造来源摘要都不能只靠自报字段通过。摘要是完整性约束，不是人工语义准确性证明。

## 未来评分协议

所有指标仅为规则，没有计算实际分值：

- Fact Support Accuracy：正确的可比较题—事实—候选单元数 / 可比较单元数；无法表达为 N/A，并报告覆盖率。
- Unsupported Claim Rate：未获许可的已发布事实数 / 已发布事实数；零发布为 N/A。
- Citation Precision：来源、事实和用途均获许可的已发布引用数 / 已发布引用数；零引用为 N/A。
- Relation Correctness：必要关系及同评论绑定均正确数 / 可比较关系数；无适用关系为 N/A。
- 可评分覆盖率：可比较单元 / 合格单元，单独列出 N/A 和执行失败；拒答率为实际明确拒答 / 已执行尝试。

unknown、未匹配、证据不足、明确反驳、拒答、执行失败及未执行分别记录。相同评论跨题按题—事实—用途分别判断，同题重复来源区间按一次计算并披露；不能当作独立买家或总体样本。组件成绩不得替代原题成绩。
