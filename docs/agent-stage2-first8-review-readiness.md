## 5. 如何逐题填写

每道题均有候选级和题级填写区，包含：直接支持、仅相关、全文上下文否决、是否需要同评论关系、关系是否满足、对象/时间错误、证据充分性、人工许可区间、澄清条件、最终判断及理由。没有勾选任何选项。

| 选项 | 人工选择含义 |
|---|---|
| A | 完整直接支持：逐事实及必要关系均充分；必须填许可区间与受限结论 |
| B | 部分事实支持：列明支持子事实及缺失项，不能当完整目标已完成 |
| C | 仅语义相关：有话题关联但不能支持所问事实 |
| D | 全文上下文否决或明确反驳：必须分别说明哪一种及依据，不能混作同一结论 |
| E | 证据不足/无法判断：说明缺失条件，不声称全库不存在 |
| F | 需澄清：保留合理候选语义及必须确认的对象/条件 |
| G | BLOCKED：来源不可读、身份/区间冲突，或必要材料阅读尚未完成 |

选项只是本轮人工工作表标签，不是Agent/API状态，也不是自动RAG发布授权。第一阶段“10轮全部A”属于其他案例，**不能沿用到本批8题**。本批只能在本人后续实际裁决后登记选择；审核时间必须来自实际裁决，不预填或追溯捏造。

填写许可区间时，请在私有表记录证据代号、实际review_id、`[start,end)`、对应完整切片与被支持事实；若是多事实/关系，分别填写并说明是否同一评论。没有选择许可的空白状态，不等于“已拒绝全部事实”，仍是PENDING。
