## 不超过五题的后续方案

建议优先预留 RB03（直接自述）、RB04（同评论关系）、RB09（相关但不支持）、RB15（反向证据与多对象）和 RB16（歧义澄清）。**当前五题均不可宣称原题已获 Runtime 评测准入**：需先逐题证明完整语义、固定候选输入适配和许可输出可比较；无法证明者保留 N/A 或先修复，禁止删条件。RB04 是关系能力缺口的代表，而不是现已支持的正例。

A 类方案仅使用冻结历史固定候选，评估命题识别、事实判断与引用许可，不评价检索召回、当前向量或新 Top-K。B 类当前真实端到端 RAG 另需当前来源与数据库身份、向量覆盖及模型与费用授权，且必须独立执行；不能从 A 推出 B。

评测前冻结单位与评分：

- **Fact Support Accuracy**：在人工已裁决且可比较的题目—事实—候选单元中，正确支持/不支持或不足的单元数除以可评分单元数；无法表达或证据未裁决为 N/A，不进入分母，同时单列覆盖率。
- **Unsupported Claim Rate**：不被人工许可的已发布事实断言数除以全部已发布事实断言数；零断言时为 N/A，不可记作 0，另报告拒答与未完成率。
- **Citation Precision**：按题—事实—引用用途计数，引用区间及来源有效且在对应事实和用途下经许可的引用数除以发布引用总数；无引用为 N/A。上下文及反例不得计入正向事实许可。
- **Relation Correctness**：对人工规定必要关系且有可比较判断的题目—关系单元，关系及同评论绑定均正确的比例；无适用关系为 N/A，跨评论拼接为错误。
- **Clarification Correctness**：以有人工指定澄清要求的题轮为分母，正确澄清且未先发布未经许可事实的比例；无适用轮次为 N/A。

同一评论在不同题目作为不同题—事实单元分别计分；同一题内重复引用相同来源区间按一个唯一引用计数并报告重复次数，不把引用数当作独立买家数。执行失败、目标无法表达、无候选与证据不足分别登记，不得统一算正确拒答；参考不随预测更改。
