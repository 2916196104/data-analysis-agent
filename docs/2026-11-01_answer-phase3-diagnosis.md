# 第三阶段回答生成诊断与实施边界

审查日期：2026-11-01。已阅读回答事实、生成、压缩、结构化结果、统计/引用校验、执行入口、二级主题及 PublicAnswerView，并检查对应测试和第二阶段报告。当前工作区保留第二阶段尚未提交的改动，不回退、不重新实现其查询与归并能力。

## 当前行为

| 类型/状态 | 当前路径 | 限制 |
| --- | --- | --- |
| 正负维度、原文、优缺点等简单请求 | 确定性模板；明确要求原因/建议/详细分析时可能调用回答模型 | 主题与观点之间缺少联系，主要罗列数据 |
| 趋势、商品比较、窗口比较、复合查询 | 回答模型选固定 summary_options 和 statements，再注入全部已选事实 | 模型没有自然解释空间，也不能选择更少但更相关的发现 |
| aspect_drilldown | 无条件 template | 只能列主题名称、数量及代表原文，无法利用主题定义组织解释 |
| insufficient_data / 全部事实为空 | 保守模板 | 无依据原因有时被泛化成“数据不足” |
| sample / full | filters 中保留范围和覆盖；模板补充分母与限制 | 模型输入没有这些字段，也没有主题或证据关联 |
| partial / failed | 任务和公开读取拦截；partial 在回答生成后改状态 | 新增回答模型前必须把 partial 判断提前，防止无意义生成和状态提升 |

AnswerValidator 当前要求摘要完全属于固定选项、items 与全部 facts 一一对应、解释由固定原句组成；AnswerAssembler 从可信事实重建数字、范围和引用。这些保护有效，但将模型约束为句子选择器。模型输入只含指标、预写命题与公开范围，排除了原文，也丢失了主题定义、完成状态和证据关联。

压缩层已保留可用的主题、分母、sample/full、coverage 和证据；统计验证与来源验证无需放宽。回答阶段已在关闭数据库事务后执行，这一边界保留。

调用链还存在目的文本丢失：自然语言下钻被编译后，answer_question 会覆盖用户原句；前端已确认追问只携带工具参数。最小修补是在现有已确认查询 JSON 中保留可选原问题，仅供回答使用，工具与参数校验不受影响；没有新增 API 字段或查询能力。

## 最小改造方案

1. 在现有 AnswerFact 上构建独立、有限的事实目录：稳定事实引用、结果引用、指标/分母、范围、主题与证据 ID、完成与样本状态、限制。增加代码可核验的同口径比较关系，避免让模型计算差异。
2. 先选择与问题相关的重点事实；强制覆盖请求维度、比较双方或正负方向，允许省略次要字段。原结果、工具计划与所有统计保持完整。
3. 简单统计继续使用保守的直接结论。主题、比较、趋势等可用结构化草稿组织重点，并生成明确标注的可能解释和分析建议；受保护值只能通过事实/证据占位符注入。
4. 自由解释不作为统计事实。结构、引用、数字、主题、范围、样本及因果边界先由代码检查，再通过独立支持性复核；无法证明支持时降级。每轮最多生成和复核各一次，无查询入口、无重新归并。
5. 生成与复核共享独立回答时间预算；记录请求数、token 用量、各阶段延迟、失败阶段和降级原因。
6. partial/failed 在模型前拦截。历史公开读取保持零模型调用，不信任持久化自由文字；必要时仅重建保守事实答案。旧草稿协议仍可安全读取。
7. 默认不向回答模型发送评论原文、服务器信息或调试字段。所有真实环境检查只在本地构建/验证事实；外部模型验收仅使用隔离合成数据，不绕过第二阶段的真实数据外发限制。

## 预计文件

- 新增 `agents/review_insights.py`：事实目录、相关性选择、草稿/支持性复核、占位符与解释验证。
- `review_answer_facts.py`、`review_answers.py`：必要元数据、精简说明、新旧生成和历史兼容。

## 风险与验收要求

自然语言支持性无法被程序完全证明。独立复核不是事实真值证明，必须保留推断标签和确定性降级，不能宣称已消除幻觉。模型超时、无效引用、伪造数字/引文、样本外推、候选主题冒充人工标签和确定因果均需覆盖拒绝测试。

首轮合成真实模型实测发现默认 15 秒作为整轮预算时降级较多。按既有配置的单请求语义，最终单请求仍受 ANSWER_TIMEOUT_SECONDS 约束，整轮至多两次该预算、最多两次请求（默认整轮 30 秒）；重试也占这两次额度。初始失败记录保留，不改写为通过。

固定问题集同时检查相关性、重点覆盖、证据支持、数字/引用、抽样限制、冗余、成本与降级；除 Schema 校验外，阅读前后回答，并对固定案例进行独立模型评审，不冒充人工验收。报告区分离线模拟、真实模型合成验收、真实 PostgreSQL 本地事实检查与未获授权的真实数据外发。
