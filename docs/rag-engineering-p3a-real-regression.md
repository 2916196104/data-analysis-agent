- 十年耐用问题已修复实体识别并进入真实检索，但 `target=null`、reason=`query_semantics_uncovered`。返回候选主要为短期故障/效果或服务抱怨，未见十年使用直接证据。必须同时记录“规则不覆盖该命题”和“本次候选没有直接证明”，不能将拒答当成已具备长期可靠性判断能力，更不能声称全库不存在。
