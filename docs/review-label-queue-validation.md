- 第一阶段：单 Worker 分块入队、Streams 消费组、数据库提交后 ACK、数据库提交失败不 ACK、ACK 丢失不重复调用、发件箱补发、Redis 丢失恢复、租约超时接管、模型已响应但未落库时允许重复调用。
- 第二阶段：15 项队列与限流测试，包括 4 个 Worker 共享总并发 2、RPM/TPM、429 Retry-After、认证暂停、恢复次数和每评论调用预算、批量拆分、正文指纹变化、Redis server epoch 冷启动保护。
- 第三阶段：7 项专项测试，包括两个独立 Windows Worker 进程、旧 run_labeling Redis 委托、导入删除联动、请求级平均/P95、回退 SQL 后重新初始化。
- 全量后端回归：237 项通过，19 项按项目现有条件跳过；包含原有评论导入、标注、任务、API、监控和 PostgreSQL 相关测试。
