# 在 IntelliJ IDEA 中选择配置并运行

项目的 42 个运行配置已保存到 [.run](../.run/)。日常直接选择带编号的配置，然后点击绿色运行按钮。配置包含脚本路径、项目根工作目录、参数及项目虚拟环境，不需要逐个手填。新增 HTTP API 使用 **69 → 70 → 71**，完整接口和后台任务用法见 [HTTP API 说明](review-http-api.md)。

名称带“调用模型”的 11、12、17、18、61 会读取本地 `.env` 并向配置的模型服务发出请求；11、12 每次最多处理 20 条评论，18 每次最多处理 200 条。17 的批次可在运行配置参数中自行修改。47、48 会保存你的告警处理决定。这里只配置入口，没有自动执行这些业务操作。

从顶部选择本文带编号的配置。右键源码文件运行可能生成另一个不含业务参数的临时配置，只显示帮助。

## 当前项目建议的运行顺序

1. **03 → 14**：先确认评论库和已有模型版本。当前库已初始化、已导入，无需重复执行 01、02、10、20、40。
2. **11 → 13**：每次标注最多 20 条，然后检查同一回放范围的进度。按需要继续运行 11，直到所需数据标注完成；若有失败，排查后执行 12。成功记录会增量跳过，12 也会处理尚未标注的记录。逐次等待结束，避免并发处理同一库。
3. **21（可选）→ 15 / 16**：需要人工复核时，启动已有工作台并访问 `http://127.0.0.1:8765`，复核后查询有效观点与证据。工作台是常驻进程，点击 IDEA 停止按钮结束。未新增前端。
4. **30 / 31 → 32 → 33 → 34**：依次检查趋势、主要问题、商品对比及原文证据。这些查询只读，可以独立重复运行。
5. **42 → 43 → 44**：逐月回放第一季度，查询运行记录，复制某条 `run_id` 在详情弹窗中查看。41 是只分析三月的替代入口，不必在 42 后额外执行。
6. **45 → 46 → 47 或 48**：有待处理告警时，先查看详情，核查后选择确认或忽略。告警为空时不用继续执行 46—48。47、48 不是需要依次执行的流水线步骤。

默认规则要求当前窗口与基线各有至少 20 条成功标注、覆盖率至少 80%、某维度负面至少 3 条、负面占比上升至少 10 个百分点，冷却期 30 天。数据不足会保存 `insufficient_data`；回放成功并不保证产生告警，不要为出现告警而降低规则。重复相同输入的分析会复用运行记录；补标或人工修改后重跑会产生新的快照。

## 从空库开始时的顺序

新环境首次运行：**01 → 02 → 10 → 20 → 40**，然后按上面的 **11 → 13 → 分析 → 回放 → 告警处理** 推进。初始化不会清空已有数据；导入会扫描完整 gzip 文件，耗时比查询长。当前原始文件路径已存在；换电脑时需自行准备对应数据和 `.env`。

60、61 是独立销售分析示例，不属于评论业务链。60 写入 `outputs/idea_sales/`；61 每次写入 `outputs/idea_sales_agent/` 下的独立运行目录。90 用于开发回归检查；91 用临时库核对完整真实数据导入，不修改业务库，报告保存在 `outputs/idea_import_validation/report.json`。

## 修改参数与排查

- 改参数：运行 → 编辑配置 → 选择带编号配置 → 修改 Parameters。复制配置可保留当前示例。
- 提示工作目录不存在：工作目录应为项目根目录，不能写成 `data-analysis-agen`。
- 提示解释器无效：确认项目 `.venv/Scripts/python.exe` 存在；本机已核对。
- 提示表未初始化：按对应功能执行 10、20 或 40；新评论库先执行 01。
- 标注配置报模型认证错误：检查本地 `.env`，不要把密钥填到可共享的 `.run` 文件。
- 44 / 46 返回记录不存在：确认复制的是同一数据库中的 `run_id` / 告警 `id`。运行 ID 不是列表序号。
- 21 提示端口被占用：停止已经运行的工作台，或修改 `--port` 后访问相应地址。
- 普通业务操作结束返回退出码 0；标注部分失败可能返回 3，查看 JSON 中的失败信息后决定是否重试。
