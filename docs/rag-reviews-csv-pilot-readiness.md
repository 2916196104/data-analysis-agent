## 结论

现有同步机制**可复用部分能力，但当前不能安全执行本次两组各不超过 50 条的真实同步**。特别是 053 被原有冻结预算约束为指定的 200 条；普通同步路径也不能保证只插入本轮缺失、已认证的观点。绕开冻结预算或直接套用普通 `--execute` 会扩大写入范围，本轮不提供伪装为安全的真实同步命令。

2026-11-12 真实盘点显示该数据源 24 款、有当前 profile 有效观点 13 款、无有效观点 11 款；E=10,676、U=400、缺口 10,276，观点覆盖约 3.75%。这是历史快照，不是本轮重新查询。055 的真实 E2E 结果与该盘点是分开证据，本轮不重跑。

## 源码核验

- `read_effective_corpus()` 使用当前正文和 profile，处理成功标注、人工修订及人工删空；`_eligible()` 绑定版本化观点 key 与每条评论快照。可作为安全预读与提交前校验基础。
- `sync_effective_opinions()` 默认 dry-run 不查询数据库、不确定待编码 key；执行时按完整评论组 `_select()` 选择前面的观点，再以 `_cached()` 按 key/space/builder 取缓存。它并不先选择“当前经认证缺失的观点”；已有向量可能占满选择上限。不能将默认 dry-run 当作实时 50 条候选预览。
- 写入阶段在 `READ COMMITTED` 下持有向量表及来源表锁，重新读取并比较当前语料，变化则拒绝；通用路径同时可能 UPDATE 旧行使其失效，遇冲突会更新向量。它还会向 `rag_embedding_sync_runs` 写入运行记录，失败时更新记录状态。因此写入、UPDATE 和失效影响必须预先量化，不能只授权“新增最多 50 条”后调用通用路径。
- 053 的 CLI 强制 `Frozen053Budget`；`check_options()` 要求 limit=200，并绑定特定候选、源快照及 055 完整行摘要。`--limit 50` 会被拒绝，不能删掉或放宽该保护。
- 已确认 profile 为 `1b58dc189d7d3ea6a55713a989f4555837eb83492690afdc020d808a268a5304`，空间由生产 `SPACE_ID` 固定为 BGE-M3、1,024 维及 `quote-utf8-v1`。本地编码无外部 API 费用，但有 CPU、内存、时间与向量存储成本；50 条 float32 向量的原始数值约 200 KiB，不含数据库索引与行开销，真实成本未测量。

## 后续真实同步的最小条件

先准备并在隔离 PostgreSQL 环境验证针对两商品的受控批次：只读快照内重新核验身份、范围、当前有效 key、18 项来源与快照，完整评论组选择最多 50 个未认证可用观点，冻结选择和完整来源摘要；确认插入、更新、失效和 055 隔离的精确影响。编码阶段使用固定本地模型与资源上限；持锁提交前重读并核对完整语料及冻结 key，严格控制 INSERT/冲突、禁止未授权 UPDATE/失效，失败回滚且不自动重试。还需独立数据库角色权限、写入额度、可验证备份与恢复方案、离线故障测试以及真实隔离库验证。

以上能力和可执行命令尚未完成并验证，故 **50 条真实同步 BLOCKED**。即使用户以后授权模型与数据库写入，也不能因此将现有 200 条冻结预算改成 50 或使用通用命令代替安全入口。权限应明确限定目标实例、商品、来源、profile、空间、最多编码和新增行数、是否允许更新或失效及单次执行窗口；实际命令待入口和测试具备后再确定。

同步后应在另行授权的只读事务中重新计算 E、U、U/E 和评论覆盖，核对 key 唯一、来源字段、快照、引用切片、模型空间、055 隔离及回滚/连接释放；同步记录和真实检索质量须分别验证。

## 数据源边界

Agent 在绑定 `reviews_csv / reviews-csv` 时仅从该来源与版本的商品目录加载商品，选中商品不属于目录则受控拒绝；检索语料也绑定同一范围。本轮发现形如 `B019GBG0IE` 的显式字母数字 ID 在某些无“的”的问句中会被漏识别并沿用已选 055。已在 `review_semantics.product_mentions()` 中最小识别 `B0` 开头的 10 位标识，并要求在 `match_product_mentions()` 按商品 ID 精确匹配，不能以本地商品标题中的相同字符冒充 ID。当前目录无该 ID 时澄清；如果原有其他数据源明确选择该商品，仍保留现有行为。此修复不新增全局禁用 Amazon 的开关，MVP 调用方仍必须固定来源/版本；其他不符合此标识模式的商品表达不保证自动发现。
