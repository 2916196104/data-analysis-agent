候选问句为“有没有配送慢的反馈？”。冻结原题是“保存的评论里，有没有明确说送货慢？请用原文支持。”原题中的配送/送货慢限定为买家反馈，本次组件问题也仅讨论同一类**买家自述配送慢**，不表示客观平均速度或总体时效。

- **COMPONENT_FACT_EQUIVALENT：true，限于上述业务事实层面。** 在本题冻结语境中，“配送慢”对应原题所问的送货慢；这不是说所有物流问题、安装等待或每种自然语言表达都会被程序识别。
- **ORIGINAL_QUESTION_EQUIVALENT：false。** 组件问句本身没有指定固定保存池、商品、日期、原文引用要求及不可外推范围，也没有执行 Router、RequestGoal 或生产来源认证。这些不能靠子问题本身补齐。

1. `target("有没有配送慢的反馈？")` 返回事实 ID `delivery_slow`，无关系项；通过。
2. “到货后等待安装”“安装等待”“安装慢”和“不是配送慢”四个短句均未被 `fact()` 识别为配送慢；通过。这只验证所列短句的解析，不证明所有否定、混合上下文或未来证据归属均正确。
3. 单独短句“送货慢”目前未被 `fact()` 识别；因此词表的实际识别覆盖窄于自然语言业务语义。组件等价不能被解释为程序可识别全部等价表述。
